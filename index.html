Installing on a mobile device

Android (Chrome)

  1. Open the app's web address in Chrome.
  2. Tap Install app on the green bar, or tap the ⋮ menu.
  3. Choose Install app (or Add to Home screen).
  4. Tap Install. The icon now appears on your home screen.

iPhone / iPad (Safari)

  1. Open the web address in Safari.
  2. Tap the Share button.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add.

Desktop (Chrome or Edge)

Click the install icon at the right end of the address bar, then Install.

Installing needs HTTPS (or localhost while testing).

Deploying to the cloud

A PWA is only static files, so any static host works. Hosts provide HTTPS automatically, which service workers require.

Option A: GitHub Pages

  1. Create a repository on github.com and upload all the project files to the root.
  2. Open Settings → Pages.
  3. Under Branch, choose main and / (root), then Save.
  4. After about a minute the app is live at https://username.github.io/repository-name/.

Option B: Netlify (drag and drop)

  1. Sign in at app.netlify.com.
  2. Open Add new site → Deploy manually.
  3. Drag the project folder onto the page.
  4. Netlify gives you an HTTPS address such as https://your-site.netlify.app.

Option C: Firebase Hosting

  1. Install Node.js, then run npm install -g firebase-tools.
  2. Run firebase login, then firebase init hosting (public folder: the project folder).
  3. Run firebase deploy.
